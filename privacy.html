Privacy

We use quote request details to respond and follow up. The quote form prepares a WhatsApp message and separately attempts to save the request securely.

We collect page views, a random browser identifier, IP address and approximate country/city for site analytics. IP addresses are removed from visit records after 30 days through scheduled maintenance. Only authorized administrators can access the dashboard. Location estimates are approximate.

We respect the browser Do Not Track preference for analytics. You can also disable analytics on this browser using the button below. Operational quote storage remains active.

To ask about your request details, contact us using the contact information on the website.
